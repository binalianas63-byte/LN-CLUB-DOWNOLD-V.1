# LN CLUB FIREBASE MULTI-APK BOT

Firebase RTDB: https://ln-apk-downold-default-rtdb.firebaseio.com/

Render Environment Variables:
BOT_TOKEN = BotFather token
CHANNEL_URL = Telegram channel URL
ADMIN_PASSWORD = Admin Panel password
FIREBASE_SERVICE_ACCOUNT = Firebase service-account JSON (one line)

Build: npm install
Start: npm start

ADMIN PANEL: https://YOUR-RENDER-DOMAIN/

IMPORTANT: Do NOT put Firebase service-account JSON or Bot Token in GitHub. Add both as Render Environment Variables. Create a Firebase service account key from Firebase Console > Project settings > Service accounts, then paste the full JSON as FIREBASE_SERVICE_ACCOUNT.
